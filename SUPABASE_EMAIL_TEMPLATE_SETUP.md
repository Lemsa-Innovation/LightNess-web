# Supabase Email Template Configuration for 6-Digit Password Reset

## Overview

This guide explains how to configure Supabase email templates to use 6-digit verification codes for password reset functionality, which works better with mobile applications.

## Configuration Steps

### 1. Access Supabase Dashboard

1. Go to your Supabase project dashboard
2. Navigate to **Authentication** → **Email Templates**
3. Select the **Reset Password** template

### 2. Update Email Template

Replace the default template with the following HTML:

```html
<h2>Reset Your Password</h2>
<p>
  You requested to reset your password. Click the link below to complete the
  process:
</p>

<div style="text-align: center; margin: 30px 0;">
  <a
    href="{{ .SiteURL }}/auth/reset-password/confirm?token={{ .Token }}&email={{ .Email }}"
    style="
      background-color: #3b82f6;
      color: white;
      padding: 12px 24px;
      text-decoration: none;
      border-radius: 6px;
      display: inline-block;
      font-weight: 500;
    "
  >
    Reset My Password
  </a>
</div>

<p style="color: #6b7280; font-size: 14px;">
  Or copy and paste this link in your browser:<br />
  <a
    href="{{ .SiteURL }}/auth/reset-password/confirm?token={{ .Token }}&email={{ .Email }}"
  >
    {{ .SiteURL }}/auth/reset-password/confirm?token={{ .Token }}&email={{
    .Email }}
  </a>
</p>

<p>This link will expire in 1 hour for security reasons.</p>

<p>If you didn't request this password reset, please ignore this email.</p>

<hr style="margin: 20px 0;" />
<p style="color: #6b7280; font-size: 14px;">
  This is an automated message. Please do not reply to this email.
</p>
```

### 3. Available Template Variables

Supabase provides these variables in email templates:

- `{{ .Token }}` - 6-digit verification code
- `{{ .ConfirmationURL }}` - Direct link to reset password (not used in this implementation)
- `{{ .TokenHash }}` - Hashed version of the token
- `{{ .SiteURL }}` - Your site URL
- `{{ .Email }}` - User's email address

### 4. Testing

1. Use the password reset functionality in your app
2. Check the email for the reset link
3. Click the link to automatically verify and proceed to password reset
4. Complete the password reset process

## Benefits of URL-Based Token Approach

1. **Mobile-Friendly**: Works seamlessly in mobile apps and web browsers
2. **Security**: Tokens expire automatically and are single-use
3. **User Experience**: One-click password reset - no manual code entry
4. **Reliability**: Works with all email clients and mobile apps
5. **Seamless Flow**: Automatic token verification from URL parameters

## Implementation Notes

- The token is automatically generated by Supabase
- Tokens typically expire after 1 hour
- The token and email are extracted from URL parameters automatically
- The verification process uses Supabase's `verifyOtp` method
- Users are automatically redirected to password reset form after verification
